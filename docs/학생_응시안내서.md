# 영어 평가 응시 안내 (학생용)

## 1. 시험 들어가기
1. 선생님이 알려 준 주소로 들어가요.
2. **학년, 반, 번호, 이름**을 써요.
3. 선생님께 받은 **응시 코드**를 써요. (예: `AB2C-DE3F`, 소문자로 써도 괜찮아요)
4. **들어가기**를 눌러요.

> 응시 코드는 나만 쓰는 비밀번호예요. 친구에게 보여 주지 마세요.
> 5번 넘게 틀리면 15분 동안 들어갈 수 없어요. 그럴 땐 선생님께 말씀하세요.

## 2. 시험 보기
- **시험 시작**을 누르면 시간이 흐르기 시작해요. 위쪽에 **남은 시간**이 보여요.
- 답을 고르거나 쓰면 **자동으로 저장**돼요. 위쪽에 「✓ 서버에 저장되었습니다」가 보이면 잘 저장된 거예요.
- **◀ 이전 / 다음 ▶** 버튼이나 아래쪽 **문제 번호**를 눌러 다른 문제로 갈 수 있어요. 파란 번호는 답한 문제예요.

### 문제 푸는 방법
- **고르는 문제**: 답을 눌러요. 다시 누르면 선택이 취소돼요.
- **O/X 문제**: O 또는 X를 눌러요.
- **쓰는 문제**: 칸에 영어로 써요.
- **철자(낱말) 배열**: 카드를 순서대로 눌러요. 잘못 놓은 카드는 위쪽에서 다시 누르면 빠져요. 「다시 하기」로 처음부터 할 수 있어요.
- **듣기 문제**: 🔊 **듣기**를 눌러요.
  - 들을 수 있는 횟수가 정해져 있어요. (예: 들은 횟수 1 / 2)
  - **⏸ 일시정지** 후 **▶ 이어 듣기**는 횟수가 늘지 않아요.
  - 처음부터 다시 들으면 횟수가 1번 늘어요. 새로고침해도 횟수는 그대로예요.

## 3. 인터넷이 끊기면?
- 위쪽에 빨간색으로 「인터넷 연결이 끊겼어요」가 나와요.
- 걱정하지 말고 계속 풀어요. 답은 기기에 보관되었다가 **인터넷이 다시 연결되면 자동으로 저장**돼요.
- 창을 닫았다면 다시 로그인해서 **이어서 풀기**를 누르면 돼요.

## 4. 제출하기
1. 다 풀었으면 **답안 제출**을 눌러요.
2. 안 푼 문제가 있으면 알려 줘요. 번호를 누르면 그 문제로 가요.
3. **제출하기**를 누르면 끝! 제출한 뒤에는 답을 고칠 수 없어요.
4. 시간이 다 되면 그때까지 쓴 답이 **자동으로 제출**돼요.

## 5. 결과
선생님이 정한 방법에 따라 점수나 문제별 맞음(O)/틀림(X)이 보이거나, 선생님이 나중에 알려 주세요.
