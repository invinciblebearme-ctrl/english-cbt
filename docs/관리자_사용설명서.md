# 관리자(교사) 사용 설명서

주소 뒤에 `/admin`을 붙여 접속합니다. (예: `https://english-cbt.학교.workers.dev/admin`)

## 0. 처음 한 번: 관리자 만들기
1. `/admin`에 처음 들어가면 「최초 관리자 설정」 화면이 나옵니다.
2. 서버에 등록한 **설정 토큰**과 아이디·이름·비밀번호(10자 이상, 영문+숫자)를 입력합니다.
3. 이 계정은 **최고 관리자**입니다. 다른 선생님 계정은 「설정 → 교사 계정 관리」에서 추가하세요.

## 1. 전체 순서
**문제은행 등록 → 학생 등록 → 응시 코드 발급·배부 → 시험 만들기(문제 선택·대상 지정) → 공개 → 응시 → 성적 확인·다운로드**

## 2. 대시보드
등록 문제 수, 시험 수, 학생 수, 진행 중인 시험(응시 중·제출 인원), 응시 완료 학생 수, 최근 결과, 수동 채점 대기 수를 한눈에 봅니다.

## 3. 문제은행
- **+ 새 문제**: 학년·단원·평가 영역·유형·배점·난이도를 고르고 문제 내용을 입력합니다.
- 유형별 입력
  - 객관식/듣기 객관식: 선택지를 입력하고 정답에 체크. ↑↓로 순서 변경
  - 그림 선택/듣기 그림 선택: 선택지마다 그림 올리기
  - O/X: O 또는 X 선택
  - 단답형: 정답(한 줄에 하나, 여러 개 모두 정답), 추가 허용 답안, 대소문자 구분·앞뒤 공백 무시 설정
  - 문장 입력형: 채점 기준 선택 — ① 정답 문장과 일치 ② 필수 낱말 포함(부분 점수 가능) ③ 교사 직접 채점. 「틀리면 교사가 다시 확인」을 켜면 오답이 채점 대기로 갑니다.
  - 철자 배열: 카드를 **정답 순서대로** 입력합니다. 학생 화면에서는 학생마다 섞여 나옵니다. 「낱말 배열」을 고르면 낱말 사이에 띄어쓰기가 들어갑니다.
- **그림·음성은 나중에 올려도 됩니다.** 자료가 없으면 「임시 저장」하세요. 화면 아래에 공개 전에 채워야 할 항목이 표시됩니다.
- 모든 항목이 채워지면 「완성으로 저장」. 시험 공개 시 임시 저장·누락 문제가 있으면 공개되지 않습니다.
- 「👁 학생 화면 미리보기」로 학생이 보는 모습을 확인합니다(초록 테두리 = 정답, 교사에게만 보임).
- 목록에서 **검색·학년·단원·영역·유형·상태** 필터, **복제**(임시 저장 상태로 복사), **삭제**를 할 수 있습니다. 이미 공개된 시험에 들어간 문제는 삭제해도 그 시험에서는 그대로 유지됩니다.

## 4. 학생 관리
- **학급 만들기**: 학년도·학년·반 입력
- **개별 등록**: 학급을 고른 뒤 번호·이름 입력
- **일괄 등록**: 「일괄 등록」 → 엑셀에서 `학년, 반, 번호, 이름` 네 칸을 복사해 붙여넣거나 CSV 파일 선택(양식 내려받기 제공). 학급은 자동으로 만들어지고, 같은 번호가 있으면 이름이 갱신됩니다.
- **응시 코드 발급**
  - 「코드 없는 학생 모두 발급」 또는 학생을 체크한 뒤 「선택 학생 코드 발급/재발급」
  - 발급 직후 창에서 **🖨 쪽지 인쇄** 또는 **CSV 내려받기**를 하세요. **보안상 코드는 이 창에서만 볼 수 있습니다.**
  - 코드를 잃어버린 학생은 재발급하면 됩니다. 이전 코드는 즉시 사용할 수 없게 됩니다.
  - 코드 상태: 미발급 / 발급됨·미사용 / 사용됨(횟수, 최근 사용 시각)
- **응시 현황**: 학생별로 대상 시험과 응시 상태·점수를 확인합니다.
- 응시 기록이 있는 학생은 삭제하면 성적 보존을 위해 **비활성화**만 됩니다.

## 5. 시험 관리
1. **+ 시험 만들기** → 편집 화면으로 이동합니다.
2. **기본 설정**: 제목, 학년·단원, 시험 시간(분), 음성 재생 횟수(0 = 제한 없음), 문제 순서 무작위, 시작·종료 시간(선택), 결과 공개 방식, 학생 안내 문구
   - 종료 시간이 되면 응시 중인 학생도 자동 제출됩니다. 학생별 시험 시간은 「시작한 순간부터 N분」이며 종료 시간을 넘지 않습니다.
3. **문항 구성**: 오른쪽 문제은행에서 「추가」, 왼쪽에서 ↑↓로 순서 변경, 문항별 배점 수정
4. **응시 대상 학생**: 학급 단위 체크 또는 「학생별 선택」
5. **👁 시험 미리보기**로 전체 시험지를 확인합니다.
6. **공개하기**: 누락 자료·임시 저장 문제·대상 학생이 없으면 무엇을 고쳐야 하는지 알려 줍니다.
- 공개 중에는 문항·배점·시간을 바꿀 수 없습니다(제목, 시작/종료 시간, 결과 공개 방식은 변경 가능). 바꾸려면 **비공개로 전환** → 수정 → 다시 공개. 이미 응시한 학생의 시험지·정답은 이전 버전으로 **그대로 보존**됩니다.
- **시험 종료**: 응시 중인 학생까지 즉시 제출·채점합니다.
- **복제**로 다른 반·다음 학기용 시험을 쉽게 만듭니다.

## 6. 성적 관리
- 시험을 고르면 대상·제출·응시 중·미응시 인원과 평균·최고·최저 점수를 보여 줍니다.
- **학생별 점수·정오표**: O(정답) / X(오답) / ?(채점 대기). 학생 이름을 누르면 문항별 응답·정답·듣기 횟수를 보고 **수동 채점**(점수 입력 → 채점)을 할 수 있습니다.
- **문항별 정답률**: 막대 그래프로 어려웠던 문항을 확인합니다.
- **응시 현황**: 미응시 학생 목록, 응시 중 학생 목록(필요 시 「강제 마감」)
- **재응시 허용**: 학생 정오표 창의 「재응시 허용」 — 기존 기록은 보관되고 학생이 처음부터 다시 봅니다. (모든 조작은 활동 기록에 남습니다)
- **CSV 다운로드 / Excel 다운로드**: Excel 파일에는 「학생별 성적」, 「문항별 정답률」, 「요약」 시트가 들어 있습니다.

## 7. 설정
- 비밀번호 변경(변경하면 다른 기기 로그인 종료)
- (최고 관리자) 교사 계정 추가·비활성화, 관리자 활동 기록 확인

## 8. 시험 당일 체크리스트
- [ ] 시험 공개 상태, 응시 대상, 시작·종료 시간 확인
- [ ] 응시 코드 쪽지 배부 (코드는 학생 본인만 보도록)
- [ ] 이어폰 연결·음량 확인(듣기 평가)
- [ ] 대시보드/성적 관리에서 응시 중 인원 확인
- [ ] 시험 후 「시험 종료」로 마감 → 수동 채점 → Excel 보관
